# UW Gamedev Club Unity Project
This is for the UW Game Dev club.


## Step 1: Install Unity
Follow the [instructions](https://docs.unity.com/en-us/hub/install-hub) to install Unity, if you haven't already.

## Step 2: Clone the repo

Fork this project.

Open your command line (Terminal) app. Ensure that you're in the folder that you want to place the project in (something like UnityProjects).
To get your directory, type:

`cd path/to/your/directory`

Click on the green code button, and a clone menu should pop up. Right now, stick with HTTPS and copy that link.

Now, in the terminal, type:

`git clone link-to-project`

Your project should be in your folder!
